# KitchenVoice 🍳🎙️

A voice-first cooking assistant that helps instinct-driven cooks and disabled chefs create, follow, and share recipes entirely by voice. Built hands-free from end to end — no reading or typing required.

## ✨ Features

### Hands-Free Voice Control
- Always-on listening during cooking sessions with a wake word (`Hey Kitchen`)
- Natural spoken commands: *next step*, *repeat that*, *convert to cups*, *how long*, *pause*
- The assistant reads each step aloud and waits for your voice to advance

### Recipe Discovery
- Speak a dish name or ingredient
- Get three visual recipe cards (photo, cook time, difficulty, ingredient count)
- Select by voice — *"open the second one"*

### Active Cooking Mode
- One large step visible at a time — no scrolling
- Voice (or tap) controls all navigation
- Automatic timers trigger when a step mentions a time

### Voice Recipe Creation
- Narrate freely while you cook
- Your narration is transcribed and structured into a formatted recipe card
- Review by listening back or viewing the large visual layout
- Save and generate a shareable card

### Smart Unit Conversion
- Speak any conversion naturally — *"convert 3 tablespoons to milliliters"*
- Instant spoken and visual answer, without leaving the cooking flow

### Accessibility Mode
- High-contrast display
- Adjustable text size (18px → 28px)
- Screen-reader-friendly, fully labeled elements
- Large 60px+ tap targets throughout
- Switch-accessible navigation

## 🧑‍🍳 Who it's for
- **Instinct-driven cooks** — visual learners, dyslexic cooks, low-literacy users who cook by feel
- **Disabled chefs & home cooks** — mobility-limited, visually impaired, or cognitively different users

## 🛠 Tech
- **Frontend:** React + Tailwind CSS (mobile-first, responsive)
- **Voice:** Web Speech API (speech recognition + spoken readback)
- **AI:** LLM recipe discovery & narration structuring
- **Backend:** Base44 functions + Recipe entity
- **Auth / DB / Hosting:** Base44 platform

1. Onboard: pick your cook profile and set accessibility preferences

3. Start cooking — follow along by voice or tap
